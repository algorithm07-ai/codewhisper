## ✨ 核心功能 / Core Features

- **🤖 AI 代码生成与补全 (AI Code Generation & Completion)**
  - 用自然语言描述您的需求，我们的 AI 助手即可生成高质量的代码片段或实时补全您的代码。让您告别重复的模板代码，专注于解决核心问题。
  - Describe what you want in plain English and let our AI Assistant generate high-quality code snippets or complete your lines of code in real-time. Spend less time writing boilerplate and more time solving problems.

- **🚀 代码优化与重构 (Code Optimization & Refactoring)**
  - 自动分析您的代码，识别性能瓶颈和改进空间。获取智能的重构建议，让您的代码更快、更整洁、更易于维护。
  - Automatically analyze your code to identify performance bottlenecks and areas for improvement. Get smart refactoring suggestions to make your code faster, cleaner, and more maintainable.

- **🧠 代码解释与审查 (Code Explanation & Review)**
  - 看不懂复杂的代码？选中它，让我们的 AI 用简单的语言为您解释。就像随时有一位高级开发人员为您进行代码审查。
  - Don't understand a complex piece of code? Select it and let our AI explain it to you in simple terms. It's like having a senior developer available for a code review anytime.

- **🐞 AI 驱动的 Bug 修复 (AI-Powered Bug Fixing)**
  - 我们的 AI 调试器可以帮助您自动识别代码中的常见错误和潜在 Bug。获得精确的修复建议，并理解问题的根源。
  - Our AI debugger helps you automatically identify and suggest fixes for common coding errors and potential bugs. Get precise suggestions and understand the root cause of the problem.

## 🚀 快速开始 / Quick Start

1.  **安装 (Install)**: 在 VS Code 扩展市场中搜索 `IntelliScript Coder`, `DeepBubble`, 或 `AI Copilot`，然后点击“安装”。
    (Search for `IntelliScript Coder`, `DeepBubble`, or `AI Copilot` in the VS Code Marketplace and click "Install".)
2.  **配置 API 密钥 (Configure API Key)**: 打开设置 (`Ctrl+,`)，搜索 `intelliScriptCoder.apiKey`，然后填入您的 DeepSeek API 密钥。
    (Open Settings (`Ctrl+,`), search for `intelliScriptCoder.apiKey`, and enter your DeepSeek API key.)
3.  **开始编码 (Start Coding)**: 打开命令面板 (`Ctrl+Shift+P`)，查找 `IntelliScript Coder` 相关命令，开始使用 AI 助手。
    (Open the Command Palette (`Ctrl+Shift+P`) and look for the `IntelliScript Coder` commands to start using the AI assistant.)
